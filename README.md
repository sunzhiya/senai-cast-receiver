# 森投屏接收端

把手机上的视频投到 Windows 电脑上播。支持 DLNA、AirPlay，也带 IPTV。

电视盒子能干的事，让电脑干一遍：手机 App 里点「投屏」，选这台电脑，视频就在电脑上放了。

## 能做什么

- DLNA / UPnP 接收：抖音、B 站、腾讯、爱奇艺、优酷这类 App 里的「TV」按钮都能搜到
- AirPlay 接收：iPhone、iPad 的隔空播放
- IPTV：自己填 m3u8 直链、m3u 列表，或者 rtp:// / udp:// 组播地址
- 播放支持 m3u8、ts、mp4、mkv，可以借用系统装的 HEVC / 杜比视界扩展
- 画质增强（对比度、饱和度、锐度）、等响度、音轨切换、字幕
- 屏幕顶部一条悬浮长条，点一下就把窗口叫回来
- 开机自启，可以选静默启动（只留在托盘）
- 主题、背景图、开屏动画都能换

## 运行环境

- Windows 10 1809 以上 / Windows 11，64 位
- 手机和电脑在同一个局域网，路由器别开 AP 隔离

## 怎么装

**微软商店**：搜「森投屏助手接收端」。

**绿色版**：下载 `森投屏接收端.exe`，双击就跑。

**源码跑**：

```
pip install -r requirements.txt
python main.py
```

第一次跑手机搜不到，点「更多 - 一键修复网络」，UAC 点「是」，然后重启软件。

## 搜不到 / 没画面

按顺序试：

1. 手机和电脑是不是同一个网。一个走 5G 热点、一个走公司网，就搜不到
2. 路由器是不是开了「AP 隔离 / 客户端隔离」，开了就关掉
3. 用 App 里那个「TV / 投屏」按钮，不是系统自带的「无线投屏」
4. 鸿蒙系统要给那个 App「附近的设备」权限
5. 还不行，点「手机连通性自检」，手机浏览器能打开那个地址，说明网是通的，问题在 App 那边

华为下拉菜单里的「无线投屏 / 多屏协同」是整屏镜像，走系统 Miracast，由 Windows 自带的「无线显示」接收。这个软件只帮你把设置入口打开，不重复实现华为私有协议。
